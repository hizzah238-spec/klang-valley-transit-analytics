# 🚆 Klang Valley Public Transit & Ridership Analytics

An end-to-end Power BI data analytics project examining public transportation passenger volume across Klang Valley (Rapid Rail, Rapid Bus, and KTM Berhad) using Prasarana Malaysia Open Data (2019–2026).

> 🎓 **Personal Portfolio Project**: Built independently as part of a data analytics portfolio for internship applications to demonstrate practical expertise in Power Query ETL, DAX data modeling, and interactive dashboard design.

## 🔑 Key Insights & Business Highlights

- **Total Passenger Volume**: Reached over **2 Billion** overall ridership across all transit services.
- **Top Transit Line**: **LRT Kelana Jaya Line** is the most heavily utilized line (~500M passengers), followed by MRT Kajang Line and LRT Ampang Line.
- **Workday vs. Weekend Demand**: Average daily ridership peaks on weekdays (**89K**) compared to weekends (**59K**), indicating high reliance on daily commuting trips.
- **Operator Breakdown**: Rapid Rail dominates overall transit share in comparison to Rapid Bus and KTM Berhad.

---

## 🛠️ Data Pipeline & Tools Used

- **Business Intelligence**: Power BI Desktop
- **Data Transformation**: Power Query (M Language) — Unpivoting wide-to-long structures, custom text trimming, and conditional columns for operator categorization.
- **Calculations & DAX**: Custom measures for Time Intelligence, Daily Averages, and Weekday/Weekend ratios.
- \*\*Data Source\*\*: Official Open Data via [data.gov.my](https://data.gov.my) (Ministry of Transport Malaysia / Prasarana).
